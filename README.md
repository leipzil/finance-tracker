# Finance Tracker — Setup

## Install
```
pip install flask
```

## Run
```
python app.py
```
Then open http://127.0.0.1:5000 in your browser.

The database file `finance.db` is created automatically on first run.

## Files
- `app.py` — Flask routes + SQLite logic
- `templates/index.html` — the page (Jinja2 template)
- `static/style.css` — styling
